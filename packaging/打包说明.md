# Windows 打包说明（Neutralino 轻量壳）

玩家版不是网页：游戏本体（src/ 打成的单文件）由 Neutralino 壳封成独立窗口的 Windows 程序。

## 复现步骤

```bash
# 1. 打单文件本体
python3 tools/build-standalone.py            # 产出 dist/yisheng.html

# 2. 准备壳工程（一次性）
mkdir -p app/resources
cp dist/yisheng.html app/resources/index.html
cp packaging/neutralino.config.json app/

# 3. 打包（需要 Node 与 @neutralinojs/neu）
cd app
neu update        # 拉各平台壳二进制到 bin/
neu build --release
# 产出 dist/AnotherLife/AnotherLife-win_x64.exe + resources.neu
```

## 分发形态

`AnotherLife.exe`（改名自 AnotherLife-win_x64.exe）＋ `resources.neu` 两件放同一文件夹，zip 分发，解压双击即玩。合计约 3.4MB（zip 后约 1.9MB）。

运行时依赖系统 Edge WebView2（Win11 自带、Win10 随 Edge 提供）。程序未签名，SmartScreen 会提示，属正常现象。

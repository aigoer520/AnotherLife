# 《一生》主线故事梳理（2026-11-05 用户定调：两端钉死，中间放开）

## 一句话主线

**出生 → 死亡，两端钉死；中间没有固定剧本，由玩家选择、随机际遇和活世界共同创作。**

## 第一条　起点：出生（钉死）

- 开局三层生成定起点：出生地（12 个文化地理区 × 地形，带地理与人文文化包）／家庭出身（富裕／小康／普通／贫寒、父母职业、家庭结构）／本人（天赋、性格、志向）。
- 出生年代随机，决定这一生的科技与社会背景。
- 人生第一幕是出生情景（如样卡 001「难产」：家人替未出生的玩家做抉择），出生结果定下健康底子，进入幼儿期。

## 第二条　中间：自由创作区（放开）

中间不设必经剧情，只设**年龄坐标**。原六段事件表从「每段必演清单」改为「每段可能性菜单」：

| 年龄段 | 只是坐标，不管剧情 | 该段高概率出现的可能性（非必经） |
|---|---|---|
| 0～6 岁 | 营养、战乱或和平、父母关系、能否上学前班 | |
| 7～17 岁 | 辍学或升学、霸凌、童工、早婚压力、第一次心动 | |
| 18～30 岁 | 高考或择业、移民、创业、恋爱结婚、第一份工作被裁 | |
| 31～50 岁 | 房贷、育儿、赡养父母、中年危机、疾病筛查 | |
| 51～70 岁 | 退休、子女远行、丧偶、投资被骗 | |
| 71 岁以上 | 慢病、遗产、回顾、告别 | |

故事由三个来源现场生成，同一局不会重样：

1. **玩家选择分叉**：点「继续生活」推进到下一个抉择点；每个选择改六维数值与三关系，后果可延迟多年才回响；18 岁、30 岁各有一次改志机会。
2. **随机际遇**：按出生地文化包、家境、年龄段、志向从事件池抽取（共通事件＋地区专属＋角色专属），触发含人生节点、随机际遇、因果连锁、状态触发、时令触发五种。
3. **活世界自转**：约 8 名关键配角各自的人生轨迹在后台自行运转，时代大势（战争、经济、技术、灾害）不随玩家意志停转；玩家干预能让配角命运偏转，多年后回响。

把「随意」串成「这一生」的，是四条跨段暗线：**健康账本、家庭账本、故土线、一生之友**——早年埋的因，晚年收的果。

## 第三条　终点：死亡与落幕（钉死）

- 死亡由**年龄＋健康账本**判定：疾病、意外、战争都可能提前带走玩家（非失败惩罚，是人生的一部分）；71 岁以上落幕权重上升。
- 死亡即收束：遗产与告别、人生回顾、关键转折回放、配角各自结局。
- 总结页：终年、人生称号（15 种以上）、总评、徽章图鉴、本局抉择次数与实际用时。

## 第四条　时长口径（不变）

开局定制：快速约 10 分钟／标准 15～25 分钟／慢品约 40 分钟／自设 5～60 分钟。靠调节事件密度实现，不砍剧情、不是倒计时逼停。

## 结构一图流

出生（定起点）→〔年龄坐标 × 自由事件池 × 活世界自转〕循环推进 → 死亡（收束总结）

# 《异生 · Another Life》对齐方案（定版汇总二，2026-11-05）

> 本方案汇总截至 2026-11-05 15:55 的全部定版决定，替代 20261105-08 旧汇总。按总则第一条：用户检查无误并明确下令后，才进入实施。

## 一、目标

做一款网页版人生模拟游戏：玩家随机（或定制）出生在全球某个家庭，以漫画剧情图推进情景抉择，从出生活到死亡，一局 15～25 分钟（可定制）打完一整个人生；每一局都是另一个人的人生。

## 二、定版要素（均已逐项确认）

1. **名称**：英文 Another Life，中文《异生》。
2. **主线**：出生 → 死亡两端钉死，中间无固定剧本。六段（0–6／7–17／18–30／31–50／51–70／71+）只是年龄坐标＋可能性菜单。故事由三源现场生成：玩家选择分叉、随机际遇（事件池按地域／家境／年龄／志向抽取）、活世界自转（约 8 名配角各自轨迹＋时代大势）。四条暗线（健康账本、家庭账本、故土线、一生之友）串联防散。
3. **开局三层生成器**：出生地（12 个文化地理区 × 地形）／家庭出身（富裕／小康／普通／贫寒、父母职业、家庭结构）／本人（天赋、性格、志向）；全随机、锁定重抽、逐层定制、8 个预设人物包四种玩法；相容表防地理矛盾组合；18 岁、30 岁各一次改志机会。
4. **文化包（双规矩，开局锁定、整局不变）**：
   - 长相包：肤色、发色、瞳色、五官、服饰、建筑随出生地（已实测：亚洲版、西欧版均对版）。
   - 语言包：剧情文本语言、人名地名名字池、称谓习惯、货币与历法节日随出生地（已演示西欧英文版）。
5. **时长**：快速约 10 分钟／标准 15–25／慢品约 40／自设 5–60，靠事件密度调节，不倒计时逼停。
6. **界面**：情景式——场景画面（漫画图）＋在场人物＋旁白／对话＋情景内选择；六维（健康、智力、魅力、财富、幸福、声望）与三关系（亲情、友情、爱情）退为顶部细条；「继续生活」推进到下一抉择点。
7. **死亡与结局**：死亡由年龄＋健康账本判定（疾病、意外、战争可提前，非失败惩罚）；落幕含遗产告别、转折回放、配角结局；总结页给终年、称号（≥15 种）、总评、徽章、本局抉择数与实际用时。

## 三、漫画剧情图生产方式（定版）

- 路线：Perchance（免费、免登录）出无字动漫图 → 按情景卡文案后期贴字拼页。已弃用 StoryDiffusion 与 AI Comic Factory（均卡在 Hugging Face 账号／令牌，且用户已下令停用）。
- 人物描述词按文化包整局锁定，保证同一人物跨格一致（样卡 001 实测一致性达标）。
- 样卡进度：001「出生·难产」已交付验货稿（20261105-11）；欧洲长相包与语言包各出验证图（20261105-12、-13）。

## 四、实施步骤（下令后按序执行）

1. **批量样卡**：其余 9 张按双规矩出图＋贴字＋逐张目检自查。拟题（覆盖六段与多区文化包）：002 学前班之争（南亚）／003 校园霸凌与第一次心动（东亚）／004 落榜与复读（东亚）／005 移民抉择（拉美→北美）／006 房贷与育儿（西欧，Lukas 线）／007 赡养父母（东亚）／008 投资被骗（北美）／009 丧偶与黄昏恋（北欧）／010 遗产与告别（撒哈拉以南非洲）。

## 五、验证方式

- 样卡：逐张目检（人物一致、长相包对版、文字无乱码、无溢出），不合格重出。
- 代码：自动模拟 100 局全程跑通出生→死亡；生成器抽取 1000 次零矛盾组合；三种时长档各模拟一局核对事件密度。

## 六、不做事项

- 不注册／不付费任何服务；不用 Hugging Face 路线；不做本地 API 服务器；只做 Windows 可用的网页版，不做原生 App 与 macOS 版；不借《西部世界》的名称、人物与乐园设定（只借活世界结构）；不做多人联网；第一版不做全语种界面（语言包先落剧情文本与名字池，界面主语言中文）。
